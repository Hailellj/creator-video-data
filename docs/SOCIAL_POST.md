# 分享文案

## 中文短版

网红视频发完了，数据和评论还要挨个平台整理。

我把这套工作流程做成了一个 Codex skill，并开源到 GitHub。给它视频清单和参考模板，就能按步骤选择采集工具、整理评论、分析反馈，再核对表格里的数值和链接。

仓库里有安装说明、合成示例和四个本地工具。工具会区分“数据是零”和“数据没取到”，中断后也能从保存的步骤继续。

实际使用要连接采集工具和飞书权限，Apify 部分服务可能收费。

项目链接：https://github.com/Hailellj/creator-video-data

## 一句话介绍

给 Codex 一份视频清单，按步骤更新数据、整理评论、分析反馈，并核对交付结果。
